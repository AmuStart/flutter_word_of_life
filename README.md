# Flutter Bible App

## A cross-platform Bible reading application built with Flutter, supporting multiple Bible translations, custom reading preferences, and persistent user settings.

## Features
- Browse Bible books and chapters
- Read scripture in multiple translations
- Adjustable font size
- Remembers last read location
- Saves user preferences between sessions
- Clean and responsive user interface
- Cross-platform support (Android, iOS)

## Technologies Used
- Flutter
- Dart
- Material Design
- SharedPreferences (for persistent settings)
- Git / GitHub

## Current Functionality
The application currently supports:
- Book selection
- Chapter navigation
- Translation selection
- Font size adjustment
- Automatic restoration of:
-- Last selected Bible translation
-- Last opened book
-- Last opened chapter
-- Preferred font size

## Planned Enhancements
- Search functionality
- Bookmarks and favourites
- Reading history
- Dark mode
- Verse sharing
- Offline content support
